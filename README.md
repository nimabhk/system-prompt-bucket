# Prompt Vault - System Prompt Library

> A curated, categorized collection of system prompts for LLMs, Custom GPTs, Google Gems, Claude Projects, and AI Agents.

This repo contains **no code** - only well-structured `.md` files you can copy-paste as system instructions.

**Languages: English & Persian (Farsi)**

## Purpose
- Share practical, tested system prompts
- Topic-based categorization for quick discovery
- Standardized format for all prompts
- Compatible with OpenAI GPTs, Google Gems, Claude, Perplexity, and any Agent Framework

## Folder Structure
```
prompts/
  01-core-roles/          # Base roles and personas
  02-coding-dev/          # Programming, code review
  03-writing-content/     # Writing, SEO content
  04-business-marketing/  # Business, marketing
  05-education-tutor/     # Education, tutoring
  06-productivity-life/   # Productivity, life hacks
  07-creative-design/     # Creativity, design
  08-agents-automation/   # Prompts for AI agents
  09-platforms/           # Platform-specific prompts
  10-translation-localization/
templates/                # Blank template for contributions
```

## Standard Format
Each file includes YAML frontmatter + System Prompt + Example Usage.

## How to Use
1. Navigate to the relevant folder
2. Open the `.md` file
3. Copy the System Prompt section

## توضیحات فارسی

> یک مجموعه دسته‌بندی شده از سیستم پرامپت‌ها برای LLMها، Custom GPTها، Google Gems، Claude Projects و ایجنت‌های هوش مصنوعی.

این مخزن **بدون کد** است - فقط فایل‌های `.md` با ساختار مناسب که می‌توانید به عنوان دستورالعمل سیستم کپی کنید.

### هدف
- به اشتراک گذاشتن سیستم پرامپت‌های کاربردی و تست شده
- دسته‌بندی موضوعی برای پیدا کردن سریع
- قالب استاندارد برای همه پرامپت‌ها
- قابل استفاده برای OpenAI GPTs, Google Gems, Claude, Perplexity و هر Agent Framework

### ساختار فولدرها
```
prompts/
  01-core-roles/          # نقش‌های پایه
  02-coding-dev/          # برنامه‌نویسی، ریویو کد
  03-writing-content/     # نویسندگی، سئو
  04-business-marketing/  # بیزنس، مارکتینگ
  05-education-tutor/     # آموزش
  06-productivity-life/   # بهره‌وری
  07-creative-design/     # خلاقیت
  08-agents-automation/   # پرامپت برای ایجنت‌ها
  09-platforms/           # مخصوص پلتفرم‌ها
  10-translation-localization/
templates/                # تمپلیت خام
```

### نحوه استفاده
1. به فولدر مربوطه بروید
2. فایل md را باز کنید
