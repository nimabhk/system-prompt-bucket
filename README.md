# Prompt Vault - System Prompt Library

> A curated, categorized collection of system prompts for LLMs, Custom GPTs, Google Gems, Claude Projects, and AI Agents.

This repo contains **no code** - only well-structured `.md` files you can copy-paste as system instructions.

**زبان: فارسی و انگلیسی**

## هدف
- به اشتراک گذاشتن سیستم پرامپت های کاربردی و تست شده
- دسته بندی موضوعی برای پیدا کردن سریع
- قالب استاندارد برای همه پرامپت ها
- قابل استفاده برای OpenAI GPTs, Google Gems, Claude, Perplexity, و هر Agent Framework

## ساختار فولدرها
```
prompts/
  01-core-roles/          # نقش های پایه
  02-coding-dev/          # برنامه نویسی، ریویو کد
  03-writing-content/     # نویسندگی، سئو
  04-business-marketing/  # بیزنس، مارکتینگ
  05-education-tutor/     # آموزش
  06-productivity-life/   # بهره وری
  07-creative-design/     # خلاقیت
  08-agents-automation/   # پرامپت برای ایجنت ها
  09-platforms/           # مخصوص پلتفرم ها
  10-translation-localization/
templates/                # تمپلیت خام
```

## فرمت استاندارد
هر فایل شامل YAML frontmatter + System Prompt + نمونه استفاده است.

## استفاده
1. برو توی فولدر مربوطه
2. فایل md رو باز کن
3. بخش System Prompt رو کپی کن
